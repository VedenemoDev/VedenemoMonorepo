Album model curl fetch suggestions

These examples assume the backend is available at http://127.0.0.1:8080 and the loaded model is AlbumCollectionSimple.

Check the dynamic API shape:

curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/_api" | jq

List artists:

curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/Artist" | jq

Find one artist by name:

curl -s --get "http://127.0.0.1:8080/data/AlbumCollectionSimple/Artist" --data-urlencode "Name=Kent" | jq

List albums:

curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album" | jq

Find albums by album name:

curl -s --get "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album" --data-urlencode "Name=B-sidor 95-00" | jq

Find albums by comment:

curl -s --get "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album" --data-urlencode "Comment=KOKOELMA" | jq

Query albums by artist relationship:

curl -s -X POST "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album/_query" -H "Content-Type: application/json" -d '{"relationships":[{"associationAzName":"Albumilla_on_esittajia","direction":"outgoing","entityAzName":"Artist","where":{"equals":{"Name":"Kent"}}}]}' | jq

Query a specific album by name, comment, and artist:

curl -s -X POST "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album/_query" -H "Content-Type: application/json" -d '{"where":{"equals":{"Name":"B-sidor 95-00","Comment":"KOKOELMA"}},"relationships":[{"associationAzName":"Albumilla_on_esittajia","direction":"outgoing","entityAzName":"Artist","where":{"equals":{"Name":"Kent"}}}]}' | jq

List album-artist links:

curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/_links/Albumilla_on_esittajia" | jq

Read the first listed album instance by ID:

id=$(curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album" | jq -r '.[0].id'); curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album/$id" | jq

Read the Kent / B-sidor 95-00 album instance by ID:

id=$(curl -s -X POST "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album/_query" -H "Content-Type: application/json" -d '{"where":{"equals":{"Name":"B-sidor 95-00","Comment":"KOKOELMA"}},"relationships":[{"associationAzName":"Albumilla_on_esittajia","direction":"outgoing","entityAzName":"Artist","where":{"equals":{"Name":"Kent"}}}]}' | jq -r '.[0].id'); curl -s "http://127.0.0.1:8080/data/AlbumCollectionSimple/Album/$id" | jq
